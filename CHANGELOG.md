# Changelog

Все заметные изменения проекта FastClickPearl.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии соответствуют [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-31

### Добавлено

- Бросок эндер-жемчуга по одной клавише (по умолчанию `V`).
- Автоматический поиск жемчуга: хотбар, основной инвентарь, вторая рука.
- Обмен жемчуга с выбранным слотом хотбара и возврат обратно, если жемчуг лежит в инвентаре.
- Экран настроек с назначением клавиши и переключателем включения.
- Кнопка `FastClickPearl` на экране заголовка и в меню паузы.
- Отдельная клавиша открытия настроек (по умолчанию не назначена).
- Конфиг `config/fastclickpearl.json`.
- Локализация: русский и английский языки.
- Отдельные сборки для Minecraft `1.21.11`, `26.1` и `26.2`.
- GitHub Actions: сборка всех версий и публикация релиза по тегу.
