**FastClickPearl** избавляет от рутины с эндер-жемчугом. Не нужно держать жемчуг в хотбаре, открывать инвентарь и перекладывать предметы: мод сам находит жемчуг, подставляет его в выбранный слот и возвращает всё на место.

Мод полностью клиентский. Он работает через обычные действия игрока — переключение слота, обмен предметов в инвентаре и использование предмета, — поэтому не требует установки на сервер.

## Возможности

| | Возможность |
|---|---|
| 🎯 | **Автоматический поиск** — жемчуг находится в хотбаре, основном инвентаре или второй руке. |
| ⚡ | **Одна клавиша** — бросок по нажатию `V` без открытия инвентаря. |
| 🔁 | **Обмен и возврат** — если жемчуг не в хотбаре, мод меняет его с выбранным слотом и сразу возвращает обратно. |
| 🖥️ | **Только клиент** — мод не нужен на сервере и не меняет его работу. |
| ⚙️ | **Свои настройки** — назначение клавиши и переключатель включения. |
| 🧭 | **Кнопка в меню** — вход в настройки с экрана заголовка и из меню паузы. |
| 🌐 | **Два языка** — русский и английский интерфейс. |
| 💾 | **Простой конфиг** — один JSON-файл в папке `config`. |
| 🧩 | **Три сборки** — отдельные jar под Minecraft `1.21.11`, `26.1` и `26.2`. |
| 🛡️ | **Без нестандартных пакетов** — только штатные действия игрока. |

## Поддерживаемые версии

| Minecraft | Java | Fabric API | Готовый файл |
|---|---|---|---|
| **1.21.11** | 21+ | `0.141.6+1.21.11` | `fastclickpearl-1.21.11-1.0.0.jar` |
| **26.1** | 25+ | `0.145.1+26.1` | `fastclickpearl-26.1-1.0.0.jar` |
| **26.2** | 25+ | `0.161.0+26.2` | `fastclickpearl-26.2-1.0.0.jar` |

Готовые сборки прикрепляются к [релизам](../../releases). Исходники каждой версии лежат в отдельной папке: `1.21.11/`, `26.1/`, `26.2/`.

Порядок поиска:

1. Слоты хотбара `0–8`.
2. Основной инвентарь `9–35`.
3. Вторая рука.

Если жемчуг лежит в хотбаре, мод переключает выбранный слот, бросает жемчуг и возвращает прежний слот. Если жемчуг в основном инвентаре, мод меняет его местами с выбранным слотом хотбара, использует предмет и меняет обратно. Всё происходит в одном тике.

## Установка

### Требования

| Компонент | Требование |
|---|---|
| Игра | Minecraft `1.21.11`, `26.1` или `26.2` |
| Загрузчик | [Fabric Loader](https://fabricmc.net/use/) |
| Зависимость | [Fabric API](https://modrinth.com/mod/fabric-api) |
| Java для игры | 21+ для `1.21.11`, 25+ для `26.1` / `26.2` |

### Шаги

1. Установите Fabric Loader для нужной версии Minecraft.
2. Скачайте Fabric API и положите его в папку `mods`.
3. Скачайте jar мода из [релизов](../../releases) и положите его в ту же папку `mods`.
4. Запустите игру.

Папка `mods` находится здесь:

| ОС | Путь |
|---|---|
| Windows | `%appdata%\.minecraft\mods` |
| macOS | `~/Library/Application Support/minecraft/mods` |
| Linux | `~/.minecraft/mods` |

> На сервер мод ставить не нужно. Он работает на стороне клиента.

## Использование

| Действие | По умолчанию |
|---|---|
| Бросить жемчуг | `V` |
| Открыть настройки мода | Не назначена |
| Кнопка `FastClickPearl` | Экран заголовка и меню паузы |

1. Зайдите в мир или на сервер.
2. Убедитесь, что в инвентаре есть эндер-жемчуг.
3. Нажмите клавишу броска.

Если жемчуг не находится, мод ничего не делает. Если жемчуг на кулдауне или открыт экран, бросок тоже не происходит.

### Экран настроек

Открыть настройки можно тремя способами:

- кнопкой `FastClickPearl` на экране заголовка;
- кнопкой `FastClickPearl` в меню паузы;
- отдельной клавишей, если она назначена.

В настройках доступны:

- **Клавиша** — открывает стандартный экран назначения клавиш Minecraft.
- **Включено** — быстро включает и выключает мод.
- **Готово** — возвращает на предыдущий экран.

Настройки слота нет: мод всегда ищет жемчуг сам.

## Настройки

Конфиг создаётся автоматически:

```
config/fastclickpearl.json
```

```json
{
  "enabled": true
}
```

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `enabled` | `boolean` | `true` | Включает или выключает бросок жемчуга. |

Назначение клавиши хранится в стандартном файле Minecraft `options.txt`, как и у других клавиш.

## Сборка из исходников

Для сборки всех трёх версий нужен **JDK 25**: Loom 1.19.3 собран под Java 25. Для запуска игры достаточно Java 21 в `1.21.11` и Java 25 в `26.1` / `26.2`. Сборка проверена на JDK 25.

### Minecraft 26.1 и 26.2

```powershell
$env:JAVA_HOME="C:\Program Files\Java\jdk-25"
cd 26.2
.\gradlew.bat build
```

### Minecraft 1.21.11

```powershell
$env:JAVA_HOME="C:\Program Files\Java\jdk-25"
cd 1.21.11
.\gradlew.bat build
```

Для Linux и macOS используйте `./gradlew build`.

### Результат сборки

| Проект | Готовый jar |
|---|---|
| `1.21.11` | `1.21.11/build/libs/fastclickpearl-1.21.11-1.0.0.jar` |
| `26.1` | `26.1/build/libs/fastclickpearl-26.1-1.0.0.jar` |
| `26.2` | `26.2/build/libs/fastclickpearl-26.2-1.0.0.jar` |

Рядом создаётся `*-sources.jar` — исходники для разработки. Для игры нужен обычный jar без суффикса.

## Честная игра

FastClickPearl не отправляет нестандартные пакеты и не обходит проверки сервера. Он выполняет те же действия, что игрок вручную:

- переключает слот хотбара;
- при необходимости меняет предметы местами в инвентаре;
- использует эндер-жемчуг;
- возвращает предметы и слот обратно.

Тем не менее автоматизация может быть запрещена правилами конкретного сервера. Перед использованием уточните правила вашего сервера.

## FAQ

<details>
<summary><b>Где скачать мод?</b></summary>

Готовые jar-файлы лежат в разделе [Releases](../../releases). Выберите файл под свою версию Minecraft.

</details>

<details>
<summary><b>Нужно ли устанавливать мод на сервер?</b></summary>

Нет. Мод клиентский и не требует установки на сервер: он работает через обычные действия игрока.

</details>

<details>
<summary><b>Почему жемчуг не бросается?</b></summary>

Проверьте:

1. Мод включён в настройках.
2. В инвентаре есть эндер-жемчуг.
3. Жемчуг не на кулдауне.
4. Не открыт экран инвентаря или другое меню.
5. Вы не находитесь в режиме наблюдателя.

</details>

<details>
<summary><b>Можно ли выбрать слот для жемчуга?</b></summary>

Нет, и это сделано специально. Мод сам ищет жемчуг в хотбаре, основном инвентаре и второй руке. Настраивать слот не нужно.

</details>

<details>
<summary><b>Работает ли мод во второй руке?</b></summary>

Да. Если жемчуг не найден в инвентаре, но лежит во второй руке, мод использует вторую руку.

</details>

<details>
<summary><b>Где хранится конфиг?</b></summary>

В файле `config/fastclickpearl.json` внутри папки игры. Там хранится только параметр `enabled`.

</details>

<details>
<summary><b>Будут ли другие версии Minecraft?</b></summary>

Сейчас поддерживаются `1.21.11`, `26.1` и `26.2`. Новые версии добавляются по мере выхода стабильных сборок Fabric.

</details>

<details>
<summary><b>Мод может конфликтовать с другими модами?</b></summary>

Обычно нет. Возможны конфликты с модами, которые перехватывают клики по инвентарю, меняют выбранный слот или блокируют использование предметов.

</details>
